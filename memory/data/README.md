# Memory Data

This directory stores persisted memory artifacts used by the assistant.

## Subdirectories

- `active/`: recent activity and rolling logs.
- `agents/`: agent-specific stored data.
- `archive/`: long-term retained records.
- `identity/`: preferences and durable identity data.
- `indexes/`: lookup structures.
- `semantic/`: semantic memory indexes.
- `state/`: serialized runtime state.
- `temporary/`: short-lived reminders and event data.
- `tools/`: tool registry artifacts.
