# Web System Docs

This directory holds documentation for the `web_system` package.

## Files

- `README_WEB.md`: quick orientation for the docs folder.
- `WEB_DESIGN.md`: architecture and implementation notes for the web stack.

## When to read these docs

- when changing `web_system/core/`
- when adding a new web backend
- when wiring web features into the tool registry or executor
